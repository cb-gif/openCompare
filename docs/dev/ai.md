# AI 开发工作流

本文是仓库共享的 AI 开发、修复、评审和计划维护规范，按用户请求决定是否修改文件。根 AGENTS.md 统一导航；.agents/skills 中的注册文件负责加载本文。

## 开始任务

- 从根 [AGENTS.md](../../AGENTS.md) 统一入口按任务导航读取规范，定位 docs/dev/plan.md 对应节点，并检查工作树与实际源码。不要重复读取已经掌握且没有变化的材料。
- 区分现有 egui 原型、目标 Tauri 桌面和文档设计。不存在的前端脚本、安装包、类型生成与 CI 不能当成已有能力。
- 核对目标行为、涉及调用方/测试/配置/文档、节点依赖和验收方法。普通修复不强制另建大计划；节点范围确实变化时更新账本。
- 多人并行前明确文件范围、DTO/锁文件/主题的负责人和交接点。发现他人改动先理解并保留；不要自行清理或覆盖。
- 分支用途按证据识别，遵守开发指南的隔离规则及当前环境 Shell 规则。用户普通开发授权不扩展为推送、PR 或发布权限。

文档职责与路径仅在 AGENTS.md 的统一导航维护，本文不重复维护目录。只读取当前任务需要的章节；发现文档与源码冲突时先说明事实，再在授权范围内修正对应来源。

## 实施时必须保持

- Monaco 管实时正文与撤销，前端文档控制器管待保存目标格式，React 不逐键复制全文；Rust 管磁盘基线的原字节/格式及原生身份。FND-01 的写入键先于 FND-06 调度和 FND-02 保存实现。
- 首版使用打开/保存/显式重比的有界完整快照。没有测量证据不引入双份实时状态或增量同步协议。
- 块接收与导航使用同源结果及两侧修订；旧结果不能编辑新正文。dirty 和保存基线同时覆盖正文/目标格式，保存回执不能覆盖新输入或新格式；仅两者均未变化才复用原字节。
- 文件写入统一走 Rust 保护路径。预览不写入；检查外部变化、根路径、类型、编码和目标新出现。失败保留原文件与编辑内容。
- 已提交的保存/复制结果必须送达；取消不撤销已成功项目，不承诺整批事务。错误、未完成、取消不能标成相同。
- 复制执行前冻结全部目标变更入口并确认 clean，期间重开不绕过保护；回执只有保护令牌/世代/正文及格式标记匹配才重载，终态统一释放保护。具体顺序以架构规范为准。
- 普通桌面单实例与 Git 独立只读进程分开；CLI 等待该次会话终态及进程退出，不以转交成功代替比较完成。
- 前端 DTO 从 Rust 生成，不手改生成物；类型不替代运行时校验。文件正文不进入日志或当作 HTML。
- 用现有组件、token、函数和依赖完成最小完整变更。改动必须到达调用方、测试、配置和文档，不提前搭建扩展平台。

## 验证与交付

先执行任务相关检查。命令以真实文件为准，现有命令见开发指南；缺工具时记录缺口，不伪报通过。新增非平凡逻辑至少有一个能证明行为的测试；纯文档运行 `node docs/dev/scripts/check-docs.mjs` 与 `git diff --check`。

涉及原生窗口、文件系统、编码或安装的功能，分别记录 Windows/macOS 证据；浏览器测试与历史原型测试不能替代原生或新桌面验收。检查器通过只能证明其检查项，不证明产品已完成。

完成后更新 docs/dev/plan.md 对应节点：只有达到完整验收且证据存在才勾选；部分实现写进行中/待验收。持久化文档只记录最终结论、实际结果、必要证据与未验证限制；不记录日常对话、用户发言、助手计划、工具调用顺序、重试过程或中断恢复经过。复现结果所必需的环境、命令和最小步骤可以保留，格式遵循质量规范。交接说明完成行为、检查和剩余项，不把聊天记录转存为项目文档。

仅评审请求不修改代码、状态或文档；报告按严重程度排序，给出文件位置、触发条件和影响。发布请求先完成具体产物与检查，再处理授权范围内的外部动作，不把 skill 当成发布批准。
