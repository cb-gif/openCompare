无窗口集成测试覆盖应用启动逻辑、后台任务和 egui 渲染，以下检查通过：

- 选中文本及二进制文件，预览显示两个文件、一个覆盖；预览阶段不写目标。
- 执行后复制两项，二进制内容一致、文本正确覆盖；目录自动刷新为零差异。
- 将目录会话写入配置，重新创建应用后恢复目录及比较结果。
- 重建文本会话后恢复路径、GBK 解码、忽略大小写、目录筛选和显示偏好。
- 查找第 5,000 字节后的中文内容，匹配范围映射正确，并出现在渲染输出中；导航切到另一侧。
- 配置损坏时保留原文件，不进入持续尝试写入的重绘循环。

复制底层测试额外覆盖相同大小与时间的内容变化、预览后新增目标、批次部分失败、取消后的逐项结果、路径穿越及文件类型冲突。复制取消后的完成报告也经过后台任务集成验证。
