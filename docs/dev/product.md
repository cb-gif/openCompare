# 产品与功能规范

## 定位与范围

openCompare 是面向开发者和本地文件维护场景的桌面比较工具。核心价值是快速找到变化、理解差异并安全处理。核心流程离线运行，Windows 和 macOS 具有一致的业务语义。产品独立实现常用比较工作流，不引入其他产品的专有代码、图标或品牌素材。

首发支持矩阵为 Windows x64 安装程序、macOS arm64 DMG、macOS x64 DMG。最低系统版本须经过依赖兼容性检查与实际安装验证后公布；目标架构、构建产物和已验证支持分别记录。Windows ARM64、Linux、移动端不属于首版发布门槛。

## 工作流

| 场景 | 操作链 | 成功标准 |
| --- | --- | --- |
| 检查文本 | 打开一对文件 → 查看差异 → 搜索/导航 | 能解释差异类型，失败、超时、格式差异不误报相同 |
| 编辑合并 | 编辑或接受差异 → 撤销/重做 → 显式保存 | 正文和目标编码/BOM/换行共同决定未保存状态，保存回执不覆盖之后的修改 |
| 检查目录 | 打开目录 → 渐进扫描 → 过滤 → 打开文件 → 返回 | 选择、展开与滚动位置保留，错误与未完成状态可见 |
| 选择性复制 | 选择文件 → 预览方向和覆盖 → 执行 → 查看结果 | 预览不写入，执行期间目标暂停编辑，拒绝已变化目标，部分成功可追踪 |
| 恢复工作 | 重新打开或切换会话 | 会话偏好、路径与标签身份正确，不静默丢弃未保存内容 |
| Git 冲突 | 传入 base/ours/theirs/output → 解决冲突 → 保存 → 退出 | output 是独立结果，未解决或取消不得报告成功 |

## 判定与错误语义

- `byte_equal`：完整内容比较确认字节相同；元数据相同不能替代此结论。
- `text_equal`：解码后的正文逐字符相同，包含换行字符；编码或 BOM 可能不同。编辑器规范化后看起来相同不能消除原文件的换行差异。
- `equivalent_by_rule`：按当前已标明规则忽略了部分差异。
- `different`、`left_only`、`right_only`、`type_conflict`：差异和操作方向清楚。
- `pending`、`running`、`incomplete`、`error`、`cancelled`：均不属于相同。父目录有错误或未完成子项时，不得显示全部相同。
- 保存或复制失败保留当前文档和错误上下文，提供重载、另存为或重新预览等可行补救；不自动重试覆盖。
- 同步计划默认普通文件内容操作，不承诺整批回滚、完整特殊元数据保留或跨进程事务。
- 仅修改编码、BOM 或换行目标也属于未保存修改，关闭时受到保护。转换失败保留正文与待保存格式，保存过程中再次修改格式不能被旧回执重置。
- 目录复制读取磁盘版本；来源有未保存编辑时明确提示。目标有未保存正文或格式时阻止覆盖；执行开始前冻结目标编辑，重开只能显示操作状态。取消或失败在写入真正停止并处理结果后解除保护，完成后不自动覆盖意外出现的新输入。
- 普通再次启动激活已有窗口，不替换未保存工作。首版 Git difftool 使用独立只读窗口显示磁盘版本，调用方等待该次比较明确完成或取消；它不能编辑输入，也不包含其他窗口尚未保存的内容。普通桌面编辑和后续 mergetool 的独立结果保存不受此范围替代。

## 版本边界

v0.1 覆盖文本、目录、手动复制、最近会话、基础 difftool 和安装包。规则/编码支持范围必须明示；复杂混合换行未验证前只读。

v0.2 增加多标签与会话增强、单向同步、可选恢复草稿、基础自定义规则、临时比较和报告；v0.3 完成三方合并与 mergetool；v1.0 完成双平台稳定性、安装升级和文档验收。扩展比较器不阻塞核心可用版。

功能分类参考 [Beyond Compare 官方功能表](https://www.scootersoftware.com/kb/feature_compare)；本产品的优先级和验收条件独立定义。注册表、媒体标签、平台专有版本资源等专用查看器暂不立项，不承诺完整复刻所有功能。

## 视觉与可访问性

- 紧凑工具栏、会话标签、可收起目录区、可调整双栏与状态栏，主空间留给文件内容。
- 中性灰基底、单一强调色；颜色、字体、间距、圆角、控件高度使用集中 token，编辑器主题同步。
- 差异同时使用色彩、图标/文字和边栏标记；焦点和选区明显，图标按钮有可访问名称。
- 浅色、深色、跟随系统；系统 UI 字体、等宽代码字体和 CJK 回退；尊重减少动态效果设置。
- 支持 Ctrl/Command 平台习惯、焦点循环、屏幕阅读器关键标签、高 DPI 与多显示器。
- 窄窗口、长路径、空态、加载、错误、密集差异、大量选择分别验收；不能只交付静态默认截图。

## 非目标

首版不提供账户、云服务、远程协作、IDE/LSP 全套能力、后台自动同步或插件市场。软件开发使用 AI 不意味着产品需要内置 AI 功能。
